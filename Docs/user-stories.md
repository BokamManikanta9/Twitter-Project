# User Stories

## Normal User Stories 

1. As a user, I want to register an account so that I can create a profile and start using the application.

2. As a user, I want to log in to the application so that I can access my account.

3. As a user, I want to create and post tweets so that I can share my thoughts and updates with others.

4. As a user, I want to view a feed containing posts from friends and other users so that I can stay updated with the latest content.

5. As a user, I want to follow and unfollow other users so that I can manage the content I see in my feed.

6. As a user, I want to like tweets so that I can show my appreciation for the content.

7. As a user, I want to comment on tweets so that I can share my thoughts and participate in discussions.

8. As a user, I want to search for users so that I can find people I want to follow.

9. As a user, I want to view my profile and tweets so that I can see the information and content I have shared.

10. As a user, I want to edit my profile information, such as my name, bio, and profile photo, so that I can personalize my account.

## Premium User Stories

1. As a premium user, I want to have all the features available to a normal user so that I can use the complete platform.

2. As a premium user, I want to have a blue verification tick on my profile so that other users can identify my verified account.
